# مجلس القرآن

عرض للمصحف على تلفزيون المجلس الرمضاني: يعمل بلا إنترنت وبلا خادم، ويُتحكم فيه بالأسهم أو بريموت Android TV.

## التشغيل

- **أسهل طريقة:** افتح `index.html` في المتصفح مباشرة (يعمل من `file://`).
- **من التلفزيون عبر الشبكة المحلية:** شغّل خادماً بسيطاً على جهاز قريب، ثم افتح عنوانه في متصفح التلفزيون:

  ```bash
  py tools/serve.py
  ```

- **من التلفزيون مباشرة:** انسخ المجلد إلى ذاكرة USB وافتح `index.html` بمتصفح يقرأ الملفات المحلية.

## التحكم

| الزر | القراءة | داخل النوافذ |
|---|---|---|
| ◀ أو ▼ | الآية التالية | التنقل بين الأزرار، و▼▲ لتمرير التفسير |
| ▶ أو ▲ | الآية السابقة | كما سبق |
| OK / Enter | قائمة الآية (كل الميزات من هنا) | تنفيذ الزر |
| رجوع / Esc | إلغاء تمييز الجذور أو الخروج من وضع الكلمات | إغلاق النافذة |

المصحف يُقرأ من اليمين إلى اليسار، لذلك السهم الأيسر هو «التالي». وعند الآية الطويلة يكشف الضغط بقيتها أولاً ثم ينتقل.

**بالفأرة أو اللمس:** السهمان الصغيران في زاويتي أسفل الصفحة (الأيسر للتالية والأيمن للسابقة) وعجلة الفأرة ينقلان بين الآيات. والضغط على كلمة يفتح معناها، والضغط على رقم الآية يفتح تفسيرها، والضغط المطوّل على كلمة يميّز جذرها في السورة، والضغط المطوّل على رقم الآية يميّز جذور الآية كلها.

**البحث داخل السورة:** من قائمة OK أو زر «بحث في السورة». اكتب رقم الآية أو كلمات منها، ولا يهم اختلاف الرسم (الصلاة والصلوة سواء). وبالريموت وحده تبدأ القائمة من الآية الحالية وتتنقل بالأسهم، وأزرار الأرقام تكتب مباشرة.

**لوحة المفاتيح:** `m` القائمة، `s` البحث في السورة، `i` الفهرس، `t` التفسير، `d` التنقل بين أوضاع الألوان، `h` إظهار تحديد الآية أو إخفاؤه، `l` الاستماع إلى الآية.

**شكل تحديد الآية:** من زر «تحديد الآية» أو قائمة OK: إطار، أو خلفية هادئة، أو خط تحت الآية، أو تلوين النص، أو تعتيم ما حولها، أو تظليل متدرج، أو شريط عند بداية كل سطر، أو النقطة الذهبية فقط، أو بدون تحديد. ويبقى الاختيار محفوظاً.

**أوضاع الألوان:** من زر «الوضع» أو قائمة OK: كحلي وذهبي، أسود، أخضر داكن، بني دافئ، كريمي كلاسيكي، ورق قديم.

## تطبيق تلفزيون Android

كل رفع إلى `main` يبني التطبيق تلقائياً عبر GitHub Actions وينشره هنا:

```text
https://github.com/Ahmedameer0/quran-majlis/releases/latest/download/quran-majlis.apk
```

الملفات داخل التطبيق، فهو يعمل دون إنترنت دائماً، وتقدمه منفصل عن المتصفح. ولا يضم تفسير الميزان، لأن ملف البناء عام.

### حدود معروفة

- التفاسير نصوص مرقمنة، وفيها أخطاء رقمنة قليلة، والآيات المقتبسة داخلها غير مشكولة.
- الشرح في المصادر مقسّم على مقاطع، فقد يظهر شرح عدة آيات معاً، وتذكر النافذة ذلك. وفي الميزان تبدأ النافذة من فقرة الآية إن وُجدت.
- المعنى في بطاقة الكلمة هو مدخل **الجذر** في مفردات الراغب، لا معنى الكلمة في سياقها. يغطي معظم الجذور.
- بعض الصفحات 14 أو 16 سطراً في البيانات، لأن عنوان السورة يقع في أعلى الصفحة التالية.

## إعادة بناء البيانات

البيانات الجاهزة موجودة في `data/`، ولا حاجة لهذا إلا عند تغيير المصادر. السكربتات في `tools/`:

```bash
py -I -X utf8 tools/build_quran.py <pages_dir> <quran-morphology.txt> data
```

```bash
py -I -X utf8 tools/build_tafsir.py <jawami|majma|mizan> <source.txt> <uthmani.json> data/tafsir
```

```bash
py -I -X utf8 tools/build_lexicon.py <raghib.txt> data/quran.js data
```

## مؤجل (المرحلة الثانية)

تتبع موضع القراءة تلقائياً من صوت القارئ، مع بقاء الأسهم للتصحيح.

## بعد أي تعديل

1. ارفع الرقم `?v=` في روابط CSS وJS داخل `index.html`.
2. شغّل `py -I -X utf8 tools/build_pwa.py` ليحدّث قائمة الملفات، وإلا بقي التطبيق المثبت على النسخة القديمة.
3. ارفع التغييرات إلى GitHub.
